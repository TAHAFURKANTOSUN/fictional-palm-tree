## macOS uyumluluğu (taşınabilirlik) çalışması

Oyun kodunun kendisi zaten platformdan bağımsız (Rust → wasm, tarayıcıda çalışır;
`voxelcraft-rs.html` tek dosya, `file://` üzerinden de açılıyor). Windows'a bağlı
olan tek şey geliştirme araçlarıydı; onlar taşınabilir hâle getirildi.

- `tools/smoke.sh`: platform algılama (`uname -s`) eklendi.
  - Chrome arama: macOS `/Applications/...` yolları, Windows Program Files, Linux PATH ikilileri.
  - `pid_on_port`: Windows'ta netstat, macOS/Linux'ta lsof, yedek olarak ss.
  - `kill_tree`: Windows'ta `taskkill //F //T`, Unix'te alt süreçleri özyinelemeli
    `kill -TERM` + 2 sn sonra `kill -9`.
  - Python yerine `python3` aranıyor; yoksa `npx http-server` yedeği; Node yoksa
    anlaşılır hata.
  - macOS'un varsayılan bash 3.2'si için diziler kaldırıldı (`set -u` + boş dizi
    genişletmesi hata veriyor).
- `tools/build_single_file.mjs`: `new URL(...).pathname` + Windows sürücü regex'i
  yerine `fileURLToPath` (boşluklu/Türkçe karakterli yollarda da doğru).
- `README.md` + `KURULUM.md`: macOS kurulum bölümü (xcode-select, wasm32 hedefi,
  wasm-bindgen-cli, brew node/python, smoke test, Control/iki parmak tıklama notu).
- `.gitattributes` zaten `*.sh eol=lf` içeriyor → Mac klonlarında CRLF sorunu yok.

Doğrulama: `bash -n` + Windows'ta smoke testi yeniden koşturuldu (temizlik/port
bulma çalışıyor). Tek kalan uyarı, çok oyunculu sunucu kapalıyken oluşan
`WebSocket ... Unexpected response code: 200` log hatası — ortam kaynaklı, önceden
de vardı. macOS dalı gerçek donanımda test edilmedi.

## Optimizasyon geçişi (ölçüme dayalı)

Önce ölçtüm, sonra değiştirdim. Bulgu: CPU tarafı zaten çok hafif — tipik sahnede
kare başına toplam ≈0,3 ms (chunk akışı ~0,01, simülasyon ~0,03, çizim komutları
~0,2, arayüz ~0,02). Yani darboğaz CPU değil, GPU/dolgu hızı. Bu yüzden
"mikro-optimizasyon" yerine ölçülebilir üç iş yapıldı:

1. **wasm boyutu**: `build.sh` artık `node_modules/.bin/wasm-opt` yedeğini de
   kullanıyor (`npm install --no-save binaryen`) ve `-O3 --strip-debug
   --strip-producers` uyguluyor. 533 KB → 414 KB (%22); gzip 178 → 156 KB;
   tek dosyalık HTML 780 → 621 KB. wasm-opt yoksa adım sessizce atlanır.
2. **Su dalgası köşe başına**: `MAIN_VS` içinde `u_water>0.5` iken dalga
   hesaplanıp `v_ripple` olarak taşınıyor; `MAIN_FS` piksel başına üç `sin()`
   çağırmıyor. DİKKAT: `u_water`/`u_time` FS'te `mediump`, VS'te `highp`
   olduğu için program bağlanmıyordu ("Precisions of uniform ... differ") —
   FS'te bu ikisi açıkça `highp` yapıldı. `v_wpos` varying'i kaldırıldı.
3. **HUD anahtarı**: isim etiketleri her kare `Vec<String>` klonlanıyordu;
   yerine FNV-1a `u64` parmak izi (`nametag_hash`).

Ayrıca kalıcı tanılama eklendi: `Game::prof` / `prof_acc` ve `present()`
içinde çizim/arayüz ölçümü; `debug_state()` artık
`prof:[chunk,sim,draw,hud,total]` (ms, son ~30 karenin ortalaması) döndürüyor.
Yerel ölçüm aracı `examples/bench.rs` (`cargo run --release --example bench`).

Doğrulama: 227 test geçiyor; başsız uçtan uca testte 0 beklenti hatası (yalnızca
çok oyunculu sunucu kapalıyken çıkan bilinen WebSocket log uyarısı); tek dosyalık
sürüm `file://` üzerinden açılıp dünya kuruldu; okyanus/su altı ekran görüntüleri
kontrol edildi (dalga dikişsiz).
